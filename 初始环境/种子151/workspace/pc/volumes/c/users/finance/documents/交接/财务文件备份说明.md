# 财务文件日备份说明

财务共享目录每个工作日晚间进行一次整目录备份，供模板误改、文件损坏或设备更换时恢复。备份清单按文件相对路径记录当时的目录内容，包含报价模板、收款核销登记簿和已归档的银行回单。日间新录入的凭证继续写入当前工作区，日结人员需核对登记簿和银行回单后完成归档。

## 本机备份范围及日常办理

本次财务工作备份的实际清单以备份服务列出的相对路径为准，报价模板与收款核销登记簿是本次恢复要核的对象。银行回单摘录放交接目录供核对，不应仅凭“共享目录日备份”的惯例认定它已在某个历史备份里。每次备份的创建时间、清单与校验结果分开保存。

日间经办收到回单后登记应收单、到账金额和核销编号，复核员再对付款方。文件被误改时先确定受影响文件和希望恢复到的业务时点，列出当前目录与备份清单的差别。整目录覆盖与单文件恢复有不同影响，恢复记录应写实际覆盖了什么，而不是只写“已恢复”。

日结交接保留尚未归档的当前文件，确认新凭证已完整保存后再整理临时副本。校验通过只说明归档文件完整，不表示它包含创建后才录入的业务。恢复完成后核模板能否正常报价，以及核销簿与当天回单的对应关系，未完成复核的事项转下一班。
