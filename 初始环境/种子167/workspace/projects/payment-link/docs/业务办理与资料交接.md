# 固定价订单支付支持与对账

## 业务安排与资料流转

商户成交后生成收款链接，客户端选择支付方式，支付渠道回执确认实际到账。固定价订单的改价与减免由商户管理，客户页面输入只说明他想付多少，不自动变更双方已确认的应收。链接重发和交易核账属于不同问题。

维护人先沿订单号查创建、链接和回执流程，核分与元的表示。验收分别记录页面提交值、可信回执实付值和订单原应收，观察何时进入已付及履约。页面体验问题可以改展示或重发方式，成交价变更仍留商户确认记录。

商户日结按订单和渠道回执核账，异常款留待处理，不用客户自行填写金额直接冲掉原应收。工单附接口差异及模拟订单结果，演示用数据不当作真实到账。回访收件仍交商户支持。
