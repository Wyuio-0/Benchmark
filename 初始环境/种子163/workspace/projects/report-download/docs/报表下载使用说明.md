# 报表下载使用说明

运营从报表页选择月份和报表类型，页面生成相对路径并调用下载入口。常用资料包括月度账单、客户对账结果和渠道汇总，报表根目录内可按月份建立子目录。接口返回UTF-8正文，由页面展示；它不是管理后台文件浏览器。

资料员发布月报时，把最终文件放入报表目录，并在页面目录登记月份与类型。下载问题先记录选择项、传入路径及错误，区分没有发布、页面路径不符与其他读取问题。相邻历史目录和内部资料有自己的保管用途，不以名字含有相同字样判断是否属于页面资料。

本地维护可用现有月度样本核返回正文，再检查其他路径的处理结果。RD工单保留复现输入和输出，完成后说明现有调用方式是否变化，便于客服解释与页面维护。测试过程中不把内部材料内容复制到客户示例或公开工单。
