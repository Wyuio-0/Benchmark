# 报表页面路径整理与维护交接

## 业务安排与资料流转

运营在报表页按月份找账单和渠道汇总，前端传相对路径给下载入口。报表目录内可能建子目录，旁边的历史和内部目录由管理岗位使用。维护工单要记录失败链接的实际路径，不能因为路径字符串长得相似就当作同一开放范围。

排查先区分页面生成路径、目录实际位置与接口返回错误，记录原调用参数及结果。实现变更保留返回格式，合法子目录样本和范围外路径分别复核。内部资料只用于本地模拟维护，不把其内容作为报表页面示例回给用户。

完成后将路径口径和接口差异给测试组，月度报表样本仍归报表根目录。历史目录的整理另开迁移事项，不用扩大下载范围代替迁移。失败用例保留原始参数，后续可复现。
