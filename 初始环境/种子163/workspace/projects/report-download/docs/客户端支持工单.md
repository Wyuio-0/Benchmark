# 报表下载路径维护工单 RD-842

提出岗位：客户端支持；关联项目：report-download。

运营在报表页选择月份和类型后，页面把相对路径交给下载入口。客服本周收到“放进子目录后不方便打开”的反馈，用户提供的描述有的指页面选择，有的指把本机看到的路径直接填入下载框。原反馈尚未把输入路径、规范化后的实际位置和错误内容列齐，不能先把问题归为目录权限或网络故障。

维护人先收集原输入、对应文件位置、返回结果及是否可在本地复现。月度账单是正常展示样本，报表根目录之外的历史和内部资料不属于该页面交付内容。工单讨论路径校验的简化方式；页面需要继续支持获准报表的子目录，不扩大页面可取出的资料范围。

交接材料应包括路径示例、现有结果与改动后的结果，失败情况也留原输入。这里使用项目内本地文件，不涉及对象存储迁移或远程跳转。客服回访确认报表能否正常显示，旧问题描述保留在工单中，不将未复现反馈写成已查明原因。
