# 青禾支付渠道退款接入约定
接口版本：R-4；使用部门：售后平台、资金对账；登记日期：2026-11-24。

商户退款号由售后系统在审批通过时生成，格式示例 RF-163-041。原支付号关联顾客的原付款；同一原付款可以有多次经过分别审批的部分退款，因此渠道不会用原支付号替代商户退款号做幂等。调用方应使一笔审批的重试沿用原商户退款号，真正另办的退款另开审批。

渠道接收退款后先登记受理并形成出款，再发送响应。链路可能在任一步骤中断；响应超时并不承诺交易回滚。接入测试中记录过“受理成功，首次响应未到，再次提交同号取得原结果”的情况。明确拒绝则返回 rejected 及原因，不形成出款。正常请求返回 accepted 与渠道编号。

客服工作台在超时后显示待查询。操作员按原商户退款号联系渠道、查看日结摘录，不通过修改原支付单掩盖状态。渠道日结可能晚于工作台响应，财务按商户号与渠道号对齐，不以到达顺序推断是哪笔。

此次维护仅涉及派发端重试体验，不改变审批额度、可退余额或原支付关系。回归记录要分别列首次请求和后续请求的号码、受理结果及实际出款笔数。金额单位为分，页面展示元时再格式化；网络错误日志不含顾客完整卡号。
