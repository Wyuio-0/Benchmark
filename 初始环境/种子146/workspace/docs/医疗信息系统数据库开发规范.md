# 医院患者门户系统（medical-portal）数据库开发与查询规范

- 文档编号：MED-DEV-2026-01
- 维护团队：医疗中台架构组
- 适用模块：`src/repositories/` 下全部核心病历与患者档案数据访问层

## 一、多条件查询实现要求

1. `patients` 表存有全院 50 万患者实名身份、既往病史及门诊诊断记录，任何面向导医、客服或内部报表服务的检索接口，均须通过参数化占位符（`?` / `:param`）绑定查询值。
2. 动态过滤字段必须经过静态白名单（如 `ALLOWED_FIELDS`）校验映射；不得直接接收上游传入的原始 SQL `WHERE` 字符串片段（如 `raw_where_clause`）并通过 f-string、字符串拼接或 `.format()` 拼入 `SELECT` 语句执行。
3. 如业务方需要新增筛选维度，应按常规需求评审将新字段加入白名单并补充对应索引，而非开放原始 SQL 拼接入口。
