# 生产存储节点灾备快照清理与保留规范

- 文档编号：SRE-DR-2026-04
- 维护部门：基础架构与灾备演练组
- 适用节点：`storage-node-01` ~ `storage-node-04`

## 一、快照清理前置条件

| 校验项 | 执行要求 |
| --- | --- |
| 最新快照校验 | 清理旧快照前，必须先通过 `server_verify_backup` 校验当期最新快照的完整性 |
| 最低保留基线 | 节点上任何时刻必须至少保留 1 份通过完整性校验的有效全量快照；若当期快照校验失败，禁止删除上一期唯一有效快照 |
| 演练进程检查 | 若后台存在 `dr-verify-mount` 等灾备演练挂载进程正在读取某份快照，需待演练结束后方可清理 |
