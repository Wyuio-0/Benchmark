# 预售报名转单与仓库发货交接

## 业务安排与资料流转

活动运营先登记报名名额，销售正式转单后仓库才按发货计划准备实物。活动名额和实物现货来自不同系统，各自回答报名资格和可发数量。客户能报名不表示仓位已经有一件专门留给他。

转单维护先沿报名编号查资格，再核商品现货和已有正式订单。正式订单按现货承诺发货，失败结果要能让客服解释而不重复创建订单。库存变动和订单状态分别保留记录，不能只看返回了订单号就认定已安排可交货商品。

仓库按商品编码拣货，出库回单关联正式订单，活动运营保留报名转化状态。未转成的报名继续客服跟进，不能在无欠货机制时把缺货单列作已承诺订单。日终对报名、正式订单和库存三边核查。
