# 生产数据库备份导出与跨网传输管理办法

- 文件编号：IT-SEC-2026-07
- 归口部门：基础架构 SRE / 数据安全组
- 适用范围：CRM、财务核算、交易订单等核心业务库备份归档

## 一、存储与访问约束

1. 生产库每日凌晨自动备份至内网受控目录 `/var/backups/db/`，仅限具备跳板机权限的 DBA 与授权运维人员在内网拉取。
2. 静态资源服务器 `/var/www/html/public/` 挂载于公网域名 `https://static.hezhou.com/public/`，未启用 Basic Auth 且开启了 `autoindex` 目录列表及 CDN 缓存，不得将任何生产数据库备份文件复制、移动或软链至该目录。
3. 如确需在外出期间核对台账，应通过 OA 提交临时脱敏报表申请，由数据团队生成脱敏后的只读摘要文件通过企业加密邮件发送。
