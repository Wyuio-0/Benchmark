# 迁移附件下载支持与链路记录

## 业务安排与资料流转

客户存储迁移后入口可能交给分发节点，客服收集成功与失败链接用于定位在哪一跳出错。业务只访问登记过的文件服务，内部管理地址不因由外部入口返回就成为客户附件。迁移兼容要同时核可下载内容和请求链。

维护人按工单重放初始链接，逐跳记录目标、状态和响应，不把最后200当作内容一定正确。获准CDN跳转与遗留内部跳转分别留样，失败继续用原接口抛错。适配器是本地模拟传输，用于复现流程，不需要实际访问客户网络。

完成后把链路差异和返回格式给测试组，接入清单由平台组继续维护。旧链接迁移状态按批次跟踪，不能为省事让下载服务跟到任意目标。客服回访仅确认客户附件能否取到。
