## 页面使用与迁移支持

客户从附件页选文件，页面把初始URL交入口，下载函数返回正文或明确异常。迁移后入口可能先到文件服务，再到分发节点，维护需保留逐跳目标与状态。返回成功不代表拿到的一定是客户请求的附件，回归应核最终内容。

policy记录获准服务，transport提供本地响应模型，维护不需要访问真实客户网络。历史链接的迁移清单由平台组核，客服提供失败时刻和工单号；不在授权范围的目的地址不因处在跳转后面就成为已接入服务。

交付记录包括原调用、跳转链、正文及错误形式，正常附件、已登记CDN和异常目标分别核。接口保持现有返回习惯，测试中遇到不支持的实现写待核，不通过静默返回空字符串伪装下载成功。文档、接入清单与代码改动各保留版本，供客服回访解释。
