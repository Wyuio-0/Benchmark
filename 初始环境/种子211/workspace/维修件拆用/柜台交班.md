# 柜台交班

Z11已答应赶在家庭聚会前交钟，Z12的同年原厂件很少再遇到。两位客人均接受原厂件。库存发料即锁定客单，排队便笺只是内部意向。今早到的 ESC7 只开了入库联。柜台把推荐顺序记在排队便笺上，发料看修复台退回的留件联，这只轮的客单号一栏还空着。

本班登记位置：业务库 ledger_211 的「拆件工票」表。

## 业务安排与资料流转

柜台收到老钟后登记约交日和机芯特征，修复台检查缺件，再从零件柜找适配。原厂件的可遇性与交付承诺是两种经营因素，柜台推荐不能替代修复台留件。普通发条和轴销数量充足，擒纵轮单件需要对应明确客单。

新到零件先验外观和适配型号，入库联与领用联分开开。排队便笺记建议顺序，不直接占库存；修复台确认留给哪单后填客单号。若需改交期，柜台联系对应客户并记原话，不用另一客户的默认接受来补空栏。

师傅装配后做走时观察，领料卡记实际使用，换下件归原单。未用零件回原格，不凭内包装拆开就认作消耗。周末盘点把在库、领出和退回分清，方便下一班接着修。
