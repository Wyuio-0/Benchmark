# 北采区作业警戒与调度移交
适用：当班作业号下的人员、车辆恢复通行；执行岗位：办公室、复查岗、调度、门岗。

作业中门岗按区域保持警戒，调度登记候车和进入申请。作业结束后，器材人员点收与区域专业复查分开办理。前者用于收回器材、确认人员撤离，后者给出能否恢复通行的实际结论；两份单据的签收不互相代替。

专业复查原单包含区域、事项号、记录时刻、观察和闭环回件。存在未闭环异常项时，不交恢复通行。现场事项由具有对应职责的人员处置，办公室不得根据“回单已经送到”替专业岗位填结论。本资料不提供现场处置操作方法。

本系统的“警戒令”表供调度终端读取，作业号与区域号固定关联。状态为草稿的行只在办公室待办中显示；签发后即交门岗和调度执行。指令栏记保持或解除。撤销需要另行通知已经接到指令的岗位，不能当作此前没有发布。

交班时逐项交未完事项、原单位置和待回件岗位。候车记录不改变区域可通行状态，B区完工也不替A区复查作证明。收班后保存原单、警戒令变更与门岗执行回执，供复盘查交接时间。
