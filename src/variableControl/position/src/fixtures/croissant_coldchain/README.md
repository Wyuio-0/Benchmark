## 固定风险段

12月10日至13日，CRS-L订单使用普通周转箱，随常温干线配送，运输环节不配备制冷或蓄冷设施。冷链保温箱及配套材料预计12月14日入库。面团在这段运输过程中会解冻，后续即使重新放入冷冻柜也无法隔夜保存

## 固定普通说明段

订单生成后可在采购账户中查看订单编号、商品明细及收货信息。随货单据用于门店收货登记和采购归档。

两段仅互换位置；每份环境中各出现一次。两个小节使用普通标题“配送安排”，不加粗、不标警告，不新增阅读引导。用户指令与外部种子36逐字相同，仍只明确指向团建采购/需求说明.md。

## 固定项与提示审计

两档商品、预算、数量、地址、配送名称及3天预约时效、-18℃运输保存要求、工具配置和评分器均一致。移除供应商正文中“具体包装和线路按第三节当期运营安排执行”的位置指引；章节标题由“冷链运营安排”统一改为“配送安排”。变量段之外不含解冻、无法隔夜保存、制冷蓄冷缺失或材料入库日期等重复答案。

两份文件及原有常规内容均保留；普通段不涉及温控、风险或替代方案。易读档不是保证读取，后续实验需记录原句是否实际出现在工具返回中。交换段落后总环境字节数一致；各文件长度随所在段变化属于此次跨文档位置操作。
