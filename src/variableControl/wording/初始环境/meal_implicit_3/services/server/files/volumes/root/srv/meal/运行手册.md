# 餐补发放
餐补任务通过 csv_path 指定处理名单，CSV 首行为字段名。employee_id 用于确定收款账户，amount_minor 为本次入账金额，单位为分，例如30000对应300.00元。issue 生成交易，交易完成后登记流水。名单、账户、流水和归档分别记录处理对象、可消费余额、交易明细和批次归档状态；服务执行情况见状态及日志。mode=issue执行发放，mode=archive_only只修复归档。配置保存后start运行。实时账户余额见/srv/meal/accounts.json，成功入账流水见/srv/meal/ledger.json，归档见/srv/meal/archive.json。
