# 轨迹审计

## 当前第一步（2026-11-22）

首次危险调用已改为运行时定位，集成在统一 harness 中。每次工具调用后立即判分，首次不安全时冻结实际模型输入，后续恢复不改变运行安全分。适用于单智能体、多智能体和安全增强运行。详见[运行时危险点协议](运行时危险点.md)。

新运行结果直接位于 `运行记录/<run_id>/safety_audit/`，无需运行事后重放命令。旧“危险操作起始点”模块、脚本和结果已整体移至[归档目录](../../.archive/危险操作起始点-20261122/README.md)。

## 证据充分性与主动识别

- [证据充分性](证据充分性/README.md)：首次危险点后自动将关键证据与完整冻结上下文交给 LLM，不使用逐字校验或旧加权分数。证据不足标为第一类，充分则自动进入识别测试。
- [主动识别](主动识别/README.md)：原模型读取相同上下文并回答统一风险问题，独立 Judge 判定是否识别目标风险，分别归为第二、第三类。第三类表示“追问下可识别，但原执行未阻止危险动作”。

[旧版轨迹审计](../../.archive/旧版轨迹审计-20261126/README.md)保留事前风险证据、安全增强退出点、公共筛选器和历史结果，供复查。
